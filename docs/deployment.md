# Правила сборки и развертывания (Deployment Guidelines)

## Изоляция релизных артефактов (#184, #72)
- Релизные tarball-архивы (`*.tgz`) ни при каких условиях не должны создаваться или оставаться в корневом каталоге репозитория.
- При ручной сборке пакета обязательно использовать параметр `--pack-destination /tmp`:
  ```bash
  npm pack --pack-destination /tmp
  ```
- В проекте настроена автоматическая проверка `npm run pack:check` (входит в `npm test` / `npm run test:all`), которая:
  - аварийно завершает сборку (`FAIL`), если в корне checkout найден любой файл `*.tgz`;
  - проверяет размер файлов в составе npm-пакета (FAIL при размере любого файла > 262144 байт, WARN при ≥ 256000 байт).
